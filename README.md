# Nalar Cipta Landing

Corporate landing page for **PT Nalar Cipta Teknologi** at `nalarcipta.web.id`.

## Stack

- Astro static site
- Single route: `src/pages/index.astro`
- Global styles: `src/styles/global.css`
- Target host: Cloudflare Pages

## Commands

```bash
npm install
npm run build
npm run preview
```

## Cloudflare Pages

| Setting | Value |
|---|---|
| Framework preset | Astro |
| Build command | `npm run build` |
| Output directory | `dist` |
| Node version | 22 |

## Notes

- English-primary corporate copy for verification reviewers.
- Visual identity is intentionally neutral and separate from BundaGizi.
- Corporate email target: `contact@nalarcipta.web.id`.
